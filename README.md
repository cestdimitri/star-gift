# Прогноз из внешнего источника

## Что здесь лежит

```
index.html                        сама страница
forecast.json                     тексты на ближайшие дни (их обновляет робот)
tools/build-forecast.mjs          забирает гороскоп с ignio.com
.github/workflows/forecast.yml    робот, который делает это раз в сутки
```

## Почему робот, а не запрос прямо из браузера

Ни один гороскопный сервис не отдаёт заголовок `Access-Control-Allow-Origin`,
поэтому страница на GitHub Pages прочитать его напрямую не может — браузер
запретит. Проверено на одиннадцати адресах: ignio.com, freehoroscopeapi,
horoscope-app-api, aztro, ohmanda, apiverve и другие. Бесплатные CORS-прокси
(allorigins, codetabs, thingproxy) мертвы, corsproxy.io стал платным.

Поэтому за гороскопом ходит робот на стороне GitHub, а страница читает готовый
файл со своего же домена. Побочная выгода: сайт продолжит работать, даже если
ignio.com однажды закроется — последний скачанный файл останется на месте.

## Что делает скрипт

Берёт из XML блок нужного знака и кладёт текст в `forecast.json` **дословно**.
Единственное, что с ним происходит, — склейка переносов строк, которые есть
в самом XML. Ни отбора по темам, ни правки обращения, ни правки рода.

Значит, на странице будет ровно то, что написал источник: обращение на «вы»
и мужской род там, где он у них стоит («вы можете оказаться нервозным»,
«пойти в гости самому»).

## Что показывает страница

Если робот принёс текст на сегодня — показывается он, со ссылкой на источник.
Если файла нет, нет сети или в нём нет сегодняшней даты — показывается
собственный банк фраз, он никуда не делся и лежит внутри `index.html`.
Восемнадцатого сентября всё перебивает поздравление.

## Запуск

1. Создать репозиторий на GitHub и положить туда все эти файлы, сохранив структуру.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Settings → Actions → General → Workflow permissions: **Read and write permissions**.
   Без этого робот не сможет закоммитить обновлённый `forecast.json`.
4. Вкладка Actions → «Прогноз на день» → Run workflow — проверить, что проходит.

Дальше он будет запускаться сам в 00:30 UTC (03:30 МСК). Ignio обновляет свой
файл в 22–23 часа по Москве, так что к этому времени текст уже свежий.

## Поменять знак зодиака

```yaml
# в .github/workflows/forecast.yml, в шаге «Забрать и адаптировать»
env:
  FORECAST_SIGN: virgo
```

Допустимые значения: aries, taurus, gemini, cancer, leo, virgo, libra,
scorpio, sagittarius, capricorn, aquarius, pisces.

## Проверить на сохранённом XML

```bash
node tools/build-forecast.mjs --from-file путь-к.xml
```

## Условия использования

Ignio разрешает брать гороскопы бесплатно и без ключа при одном условии:
на странице должна стоять открытая для поисковиков ссылка на ignio.com.
Она уже есть — появляется под прогнозом, когда показан их текст.

Ещё одно их ограничение: скачивать файл не чаще раза в час, иначе блокировка.
Робот ходит раз в сутки, так что запас большой.
