# Как править тексты

Все тексты страницы лежат здесь, в обычных текстовых файлах.
Правьте их чем угодно, потом одной командой соберите страницу.

```bash
node tools/build-page.mjs --check   # только проверить, файл не тронет
node tools/build-page.mjs           # собрать index.html
```

## Что где

```
nastroenie.txt · mysli.txt · lyudi-ryadom.txt · dela.txt
telo.txt · dom.txt · razgovory.txt · tishina.txt    восемь тем
slovari.txt                                         «делать» и «избегать»
pozdravlenie.txt                                    текст на 18 сентября
```

## Формат

Одна фраза — одна строка. Пустые строки и строки, начинающиеся с `#`,
пропускаются. Разделы начинаются с `##`.

```
## CONJ — начало, фокус на себе

Сегодня хочется начать что-то с чистого листа.
Утро располагает заняться собой, а не чужими делами.
```

Менять названия разделов нельзя — по ним собирается страница.
Пояснение после тире можно править как угодно, оно ни на что не влияет.

## Шесть разделов в каждой теме

Это интонация дня. Она выбирается по настоящему положению Луны:
аспект к натальному Солнцу, а когда аспекта нет — по фазе.

| Раздел | Когда показывается | О чём фразы |
|---|---|---|
| `CONJ` | соединение, и в новолуние | начало, фокус на себе |
| `SEXTILE` | секстиль, и на растущей Луне | лёгкость, можно просить |
| `SQUARE` | квадратура | сопротивление, день усилия |
| `TRINE` | трин | всё идёт само, не мешай |
| `OPPOSITION` | оппозиция, и в полнолуние | про других людей, про зеркало |
| `NONE` | на убывающей Луне без аспекта | ровный день, ничего не форсировать |

Как часто какой выпадает, за пять лет: SEXTILE 24%, OPPOSITION 22%,
CONJ 21%, NONE 17%, TRINE 9%, SQUARE 7%. То есть первые три раздела
она увидит чаще остальных — на них стоит потратить больше сил.

## Сколько фраз нужно

Минимум три в разделе, иначе сборка откажется. Больше — лучше:
в один день показываются четыре темы, и фраза в теме меняется каждый день,
проходя весь раздел по кругу. Двадцать фраз — это цикл в двадцать дней.

Темы выбираются по стихии знака, в котором Луна:
огонь — Тело, Дела, Разговоры, Люди рядом;
земля — Дела, Дом, Тело, Тишина;
воздух — Разговоры, Мысли, Люди рядом, Тишина;
вода — Настроение, Люди рядом, Дом, Тишина.

## Что проверяет сборка

- в разделе не меньше трёх строк
- нет повторов внутри раздела
- нет строк вне разделов и лишних разделов

Чего она не проверяет — смысл, длину и интонацию. Это на вас.

Ещё в странице есть защита от совпадений: если две фразы дня начинаются
с одного слова, вторая заменяется на следующую по списку. Так что
одинаковые начала не страшны, но и злоупотреблять ими не стоит.

## Если что-то пошло не так

`node tools/build-page.mjs --check` печатает все проблемы списком
с номерами строк и ничего не трогает. Сборка без `--check` при любой
найденной проблеме тоже откажется писать файл.
